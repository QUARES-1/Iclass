## 启动

当前环境已安装 Node 依赖、项目专用 Python 3.11 环境及 Whisper small 权重。在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:3000。使用 Ctrl+C 停止 Node 及其转写进程；退出时未完成的备课任务下次启动后变为可继续的暂停，已完成批次保留；音频任务的分段进度保存在本地，重启后可继续；完整转写和报告在任务最终完成后提交，已保存录音不受影响。

在新环境中准备：

1. Node.js >=20.12、Python 3.11、Google Chrome。互动候选在后端使用本机 Chrome 检查主要操作，通过后才保存；不需要下载 Playwright 浏览器。
2. 运行 `npm ci`。
3. 建立 Python 环境并安装依赖：

   ```sh
   python3.11 -m venv .venv
   .venv/bin/python -m pip install -r speech/requirements.lock.txt
   .venv/bin/python speech/prepare.py
   ```

   模型准备会下载现成权重至 `data/models/whisper-small/`，不是训练。当前选择 faster-whisper CPU/int8；Paraformer 是原需求的候选建议，本次针对当前 Mac 采用已实测的路径。推理使用本地权重，不在用户提交录音时自动联网下载。
4. `npm start` 后打开页面中的“模型与提示词设置”，填写 API 基础地址、模型名称和密钥并保存。也可先 `cp .env.example .env` 填写初始配置；教师后续在界面保存的配置优先，无需重启。密钥只保存在 Node 后端。PPT 生成、对话修改与报告分析需访问所配置的文本模型；录音识别与导出的 HTML 可离线运行。未配置密钥时可先点击“载入本地示例”试玩、编辑、确认与导出。

FFmpeg 由 imageio-ffmpeg 依赖随附，可通过 `FFMPEG_PATH` 使用其他版本。`PYTHON_BIN` 可指定其他已配置的 Python。锁文件记录本机实测组合，其他操作系统仍需重新验证。

## 使用工作台

“模型与提示词设置”可调整备课、资料理解、课堂复盘的程序提示词和 API 连接，保存后即时生效；测试连接不自动保存。课件详细扩写会在保存前自动拆页，页面总数没有原先 15/150 页的业务上限；单次输出须符合模型服务商额度，长课程由智能体自动分批生成，遇到输出超限自动缩小批次。规划、生成与检查进度可见，支持暂停、恢复和查看任务草稿。详见 [设置说明](docs/model-settings-fix.md)。

“载入本地示例”只补齐缺少的样例，重复点击不会追加或覆盖已有修改。旧版完全重复的样例会整理，修改/确认/引用及当前选中的资源保留；整理前完整备份至 `data/backups/`。

- 填写教学要求，上传 TXT、MD、DOCX、PPTX 或粘贴文本；展开“查看解析内容”核对正文，没有文件时也可提出明确需求。失败资料保留文件名与错误，不进入 AI 资料正文。单份 ≤15 MiB、最多 20 条（含失败记录）、UTF-8 文本；每份正文最多保留 25 万字符、合计 50 万；图片文字不做 OCR，不能上传加密 Office 文档。文件要求和 AI 上下文限制详见 [边界复核](docs/upload-boundary-review.md)。
- 在同一工作台查看、调整知识点和本地知识库补充。资料理解使用教师配置和完整已解析正文，超出所设输入额度时明确提示；规则回退会标注“非 AI”；资源对话失败不会用模板覆盖已有成果。
- 对话可以聊天、解释、查看内容或要求执行；明确修改时默认使用当前资源，可展开“操作对象与修改范围”选择整份 PPT 或某一页。发送前会保存编辑器中的人工修改，模型使用最新保存版本。简单操作直接执行，复杂备课才规划；任务执行期间仍可聊天和查看进度。
- 对话区右上角“清空上下文”可删除全部历史交互记录，让新要求不再使用旧对话；保留资料、资源、历史版本和教师设置。运行中的任务请先暂停，清空后旧暂停任务不能继续，详见 [清空说明](docs/conversation-context.md)。
- 示例代码优先按完整函数分页，可编辑并复制整份程序；“版本与更多导出方式”中的“按函数整理代码分页”可整理已有代码课件。很长的函数仍会分段，详见 [分页说明与验证](docs/code-pagination.md)。
- 小游戏与教学网页支持点击答题、拖拽/按钮排序、配对、步骤推进。AI 生成声明式内容与规则，应用提供固定运行器；不执行模型编写的任意 HTML/JavaScript。修改可调整题目、答案、反馈、排序规则等首版能力；超出支持模式的要求需澄清。
- 每次实质修改保留版本，并使受影响内容待确认。撤销或恢复会建立新版本，历史分支保留，恢复内容需要再次确认。
- 当前 PPT 全部有效页面确认后才能导出完整正式稿。互动的当前版本须确认后正式导出；草稿可随时导出并标明状态。
- PPTX 标题、正文和页脚使用宋体（SimSun），代码与运行输出使用 Consolas，保留原始换行和缩进。没有附加内容的概念页采用通栏，不显示空的“关键理解与辨析”；示例页保留完整正文，只显示已有的示例或反例。
- 每页标题尽量对应本页知识点、函数或操作环节；自动分页不再往标题叠加“续页”编号，旧标题中的自动后缀也会在 PPTX 大标题中清除。代码分段位置仍以独立的小字号标识显示。
- “放入本页”或对话关联互动时固定引用版本。PPT 页面含静态示意、教师操作说明与本地打开入口。导出 ZIP 内含 PPTX、Markdown、对应 HTML 与说明，解压到同一文件夹；如演示软件不允许本地链接，可直接在浏览器打开 HTML。后续修改互动不会改动已关联的快照。

## 使用音频复盘

上传 WAV、MP3、M4A、WebM（录音环境需要时也接受 OGG），或授权麦克风录制。停止后得到完整录音，先回放、保存，再单独启动转写。默认限制 512 MiB / 3 小时，页面显示后端配置的实际限制。文件需有可解码音轨、内容与扩展名一致；不接受带真实视频轨的文件。上传有进度和取消入口，停止后的录音也可以放弃，再改用上传文件。

录音流式写入文件，Node 串行协调独立 Python 推理进程。默认每 180 秒处理一块，边界重叠 2 秒；块内使用 VAD 语音区间和模型词对齐，叠加真实区间与块偏移，以时间归属合并重叠区文本。时间来源保存在片段中，没有均匀分配的伪造时间戳。模型处理状态显示为实际阶段，无虚构百分比。

中文识别结果保存后通过本地OpenCC字形转换默认使用简体；繁体识别原稿作为独立版本保留，时间戳与片段ID不变。现有转写可点击“统一为简体”，保留教师校正历史；当前有效报告形成可追溯的简体文字版，不重新分析录音。识别原稿保留。教师可以播放片段、修改文字并保存校正版；录音、校正版或课程说明改变后，旧报告标为待更新。默认生成一份统一总结（长课堂通常400～700字、建议1000字符内，可用2～3个自然段）和根据课堂实际需要展开的行动建议（不限定固定条数与字数）；展开“按需细分分析”，选择知识点、重点、潜在难点或表达与时间节奏并提出要求，才生成对应内容。细分内容保留已有总结与教师修订，默认折叠；修订与依据也按需展开。旧版详细报告保留，点击“生成总结与建议”可生成新的整体复盘。报告支持原文证据、结论类型、修订与确认及 Markdown 导出。长文本逐段处理并记录覆盖范围，篇幅建议用于精简，不将字数偏差等同于证据或生成失败；模型精简失败时仍保留此前已验证的完整候选。缺少证据或未完整返回的分段不会显示为完整报告。转写和分段分析任务支持暂停、取消及断点继续；暂停会保留已完成分段，最终整课汇总仍需完成。

首版分析整段课堂录音，不宣称完整说话人识别。文字节奏为字数/识别片段时长的估算，片段间隔不代表精确静音；报告不推断学生掌握或专注情况。现有视频与抬头率功能、模拟数据、图表、派生事件和导出字段已清理。

“完整转写汇总”提供整段全文、当前校正版与识别原稿切换、时间显示以及TXT导出，不受分页或搜索限制，独立于AI总结。导出先保存校正，不截取当前页。转写按60片段分页，支持术语搜索、时间定位和排除误识别片段；排除不删除原稿与时间。播放器固定在页面底部，片段回放后可继续播放整段。浏览器不能直接播放的音频会生成MP3回放副本，识别仍使用原文件。替换录音前自动保存当前校正；无版本引用的旧文件会清理，有转写引用的录音保留在历史中。历史录音、转写与报告修订可选择恢复。

报告导出先保存校正与修订，按对应版本下载；下载等待期间继续修改会阻止旧稿导出，保留输入供重试。支持整体确认，以及展开“讨论或调整这份复盘”进行问答、修改已有措辞或请求指定细分分析；问候不会自动启动分析。“清空讨论上下文”保留录音、转写与报告。时间估算须提供起止片段，程序计算跨度或间隔，不能据此宣称连续讲授或学生实际掌握程度。

## 保存与恢复

`data/workspace.json` 与 `data/classroom.json` 分别保存两条流程；录音在 `data/audio/`。采用串行提交、revision 冲突检查与临时文件原子替换，保存失败时保留输入，不能覆盖已保存成果。AI 请求期间发生人工修改会拒绝候选覆盖，错误可重试。

浏览器刷新及服务重启后恢复已保存数据；仍在录制或未保存的表单会提示离开风险。清空课堂会删除其录音与转写/报告；单独删除音频前提示失去回放，保留文字但将报告标为待更新。数据和密钥目录不由静态服务公开。

## 验证

```sh
npm test
npm run test:browser
.venv/bin/python scripts/verify-speech.py
.venv/bin/python scripts/verify-upload-boundaries.py
```

浏览器测试使用本机 Chrome、模拟录音设备、明确标记的模型测试接口；语音识别使用真实本地模型。运行语音检查前需准备官方短样本到 `artifacts/audio/asr-example-zh.wav`：

```sh
mkdir -p artifacts/audio
curl -L --fail https://isv-data.oss-cn-hangzhou.aliyuncs.com/ics/MaaS/ASR/test_audio/asr_example_zh.wav -o artifacts/audio/asr-example-zh.wav
```

语音检查包含真实 MP3/M4A/WebM 识别、无语音、坏文件，以及 220 秒合成边界夹具。它不替代 45～100 分钟完整课堂录音。浏览器测试的接口模型也不替代真实 DeepSeek 内容质量验收。结果与证据记录在 [验收记录](docs/acceptance.md)，原始产物写入忽略版本控制的 `artifacts/`。

本机真实课堂样本为北京大学计算机网络第一讲的完整公开音轨（49 分 35.8 秒），来源及音频指纹见 [真实验证记录](docs/live-validation.md)。服务运行时可继续已有录音的验收：

```sh
node scripts/verify-classroom-live.mjs transcribe
node scripts/verify-classroom-live.mjs analyze
```

转写在本地执行；分析会将该公开课堂转写和独立课程说明发送给已配置的真实文本模型。脚本检查固定音频指纹，不替换已有的其他课堂录音，分析输入和结果保存在 `artifacts/live/`。生成报告后仍需教师复核与确认。

当前课堂样例保留 845 段原稿、4 处术语校正及旧版六类真实分析；修订后报告为 `artifacts/live/classroom-reviewed-report.md`。本机语音进程耗时约 15 分钟、峰值 RSS 约 1.52 GiB。识别仍有同音词及专名错误，模型报告也可能误算时间或引用不足；原音频、原稿、证据回放及人工修订用于复核，不能将自动验收确认视为教师已批准内容。

## 排查

音频完善与新增验证见[音频复盘修复验证](docs/sprint2-improvements.md)。

- 模型密钥未配置/超时：打开“模型与提示词设置”调整密钥、模型和超时，测试连接后保存；已有资源、录音与报告保留。密钥只在设置页专用输入框填写，不粘贴到教学对话。
- 本地语音模型不可用：检查 `.venv`、`ASR_MODEL`，运行模型准备脚本。无语音、坏文件与资源不足会报告失败，不自动插入示例转写。
- 互动运行检查失败：确认 Chrome 已安装，检查 `PREVIEW_BROWSER`；候选不会替换已有资源。`PREVIEW_BROWSER=chromium` 需要另行准备 Chromium。
- 麦克风权限被拒绝：在浏览器站点权限中允许后重试，或上传已有录音。请通过本机 HTTP 地址访问页面。
- 版本冲突：保存当前未提交文字到本地，刷新后按最新内容重试；系统不会静默覆盖其他操作。
- 语音识别错字：用原音频核对并校正。当前 short 样本存在“达摩院”识别为“打磨院”的错误，未承诺术语识别准确率。

技术依据：[faster-whisper 官方用法](https://github.com/SYSTRAN/faster-whisper)、[FunASR 官方中文样本与候选方案](https://github.com/modelscope/FunASR)。
