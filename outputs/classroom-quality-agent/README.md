# 课堂质量改进智能体

供教师本地使用的课程教学智能体。首页按课程组织，每门课程包含多个课次；每课次集中管理教学资源、备课、课堂录音与课后反馈。

- **备课工作台**：上传资料，与智能体讨论，生成和修改PPT、小游戏及教学网页，管理版本并导出。
- **音频复盘**：上传或录制课堂音频，本地转写、校正、查看完整简体全文，生成整体总结和改进建议，回听原文依据。
- **课后反馈**：编辑问卷模板，课程结束时发布到金数据，汇总反馈与课堂资料形成整体复盘，将所选 PPT 建议带入备课工作台。

每个课次的内容、任务和草稿独立保存；模型连接和默认问卷模板共用。教师可以上传自己的课件、讲义、图片或添加网页链接，同一节课可使用多个外部与生成资源，不要求先生成PPT。AI生成与分析使用教师配置的在线模型；音频识别在本机执行。

从首页进入“课程 → 课次概览与资源”，再按需进入备课、课堂录音和课后反馈。旧全局数据保留在“历史教学资料 → 原有工作区”，不会自动复制或推断课程归属。文件要求、复用、归档与建议交接见[课程与课次说明](docs/course-structure.md)。

设置页的“数据与恢复”提供空间统计、历史归档与补回、无引用数据清理。保存自动保留有效副本，前两个工作区的编辑草稿可在刷新后恢复；使用方法和边界见[数据恢复说明](docs/data-recovery.md)。

## 首次安装

拿到源码后需要安装依赖和准备模型。macOS有完整课堂验证记录，Windows有短音频及页面验证记录，Linux需要在实际部署环境验证；具体范围见[验证状态](docs/acceptance.md)。

| 准备项 | 用途 |
| --- | --- |
| [Node.js](https://nodejs.org/en/download)，建议24 LTS，项目要求≥20.12 | 服务和JavaScript依赖 |
| [Python](https://www.python.org/downloads/) 3.11 | 音频探测、转换和识别 |
| [Google Chrome](https://www.google.com/chrome/) | 使用界面、后端互动操作检查 |
| Whisper small权重，约0.5 GB | 本地语音识别，由准备脚本下载 |
| 可用的文本模型API Key | AI对话、备课和报告，由使用者配置 |

安装运行环境后，从仓库根目录执行：

```sh
cd outputs/classroom-quality-agent
npm ci
python3.11 -m venv .venv
.venv/bin/python -m pip install -r speech/requirements.lock.txt
npm run speech:prepare
npm start
```

打开 **http://127.0.0.1:3000**。页面会检测模型API地址、模型名称和密钥，缺失或格式不符时主动显示填写向导；首页与反馈页还会引导配置可选的金数据连接。已有密钥留空保留，测试连接不自动保存。点击“稍后配置”后，本标签内不再反复弹出，页面保留“补齐配置”入口；也可随时进入完整设置。

运行时需同时保留相邻的 `outputs/classroom-feedback-api/`，主应用复用其中的问卷客户端、默认定义和样例。无需另外启动问卷服务，也无需在该目录安装依赖。

首次安装需要联网下载依赖和模型。权重默认保存在`data/models/whisper-small/`，之后识别可离线运行。FFmpeg随Python依赖提供，默认使用CPU，无需另装显卡运行环境。

只体验界面、资料编辑和本地示例时，可以先执行`npm ci`、`npm start`；音频功能需要Python环境，AI功能需要可用的API配置。详细步骤与平台限制见[部署说明](docs/setup.md)。

## 模型配置

设置页可调整API Key、API地址、模型、提示词、输入输出额度和任务预算。保存后用于后续请求，正在执行的请求使用发起时的配置。“测试当前连接”不自动保存。

新安装的初始最大输出额度为8000 token，可按所选模型能力调整，例如32768；额度针对每次模型请求。也可复制`.env.example`为`.env`设置初始参数，界面保存的配置优先。

仓库不包含API Key、个人配置、录音、下载的模型或已生成课件。新使用者需要自行配置和上传资料。

## 备课工作台

1. 填写教学要求，上传TXT、MD、DOCX、PPTX或粘贴文本，核对解析内容。
2. 与智能体讨论或提出生成、修改要求。普通问答直接回复，复杂备课任务会规划、读取资料、分批执行和检查修正。
3. 切换资源、人工编辑、选择修改范围、查看任务草稿，或暂停后继续。
4. 确认内容后导出PPTX或独立HTML；关联互动的PPT可导出配套ZIP。正式PPT须确认全部有效页面，未确认时可导出草稿。

“载入本地示例”只补齐缺少的样例，重复点击不会复制资源。“清空上下文”清除对话，保留资料和成果；有任务运行时请先暂停。

资料默认单份最多15 MiB、最多20条，文本须为UTF-8。Office图片中的文字不做OCR，加密文档不支持解析。长代码优先按完整函数或代码部分分页，超长函数仍可能跨页。PPTX正文使用宋体，代码使用Consolas，接收方电脑需要具有相应字体。

## 课堂音频复盘

1. 上传WAV、MP3、M4A、WebM或OGG，或授权麦克风录音。录音停止后先回放、保存，再点击转写。
2. 在“完整转写汇总”查看全文、切换原稿与当前版本、显示时间或导出TXT。展开片段列表可校正、搜索、定位时间或排除误识别。
3. 点击“生成总结与建议”。默认展示一份整体总结，改进建议按实际课堂问题展开，不按固定条数或字数裁剪。
4. 按需生成知识点、重点、潜在难点或表达与节奏分析，也可展开讨论入口追问和调整措辞。
5. 回听依据、修订并确认结论，导出Markdown报告。

音频默认最多512 MiB、3小时，页面显示实际限制。文件需有可解码音轨且与扩展名一致，视频需先提取音频。部分编码会生成兼容的回放副本。

默认使用简体转写，识别原稿与校正历史保留，时间戳和片段ID不变。转写与分析支持暂停、取消和从已完成分段继续。更换录音、修改课程或校正文字后，已有报告标记待更新，原报告仍可查看。

复盘不区分全部说话人。时间观察基于识别区间与片段间隔，不能据此判断学生掌握程度；识别文字与AI结论需要教师核对。

## 课后反馈与教学改进

1. 新建课堂，在“编辑问卷模板”中修改题目、题型、选项、排序和必填状态，预览后保存。默认有9道题，课堂归属由系统记录，学生无需选择课堂。
2. 在设置页填写独立的金数据 Access Token 和 API 地址，测试后保存。模型密钥与问卷凭据分别管理。
3. 点击“课程结束”，系统立即按已保存模板开始发布。成功后显示填写链接与二维码；缺配置保留待发布状态，创建结果不确定时先核实已有表单，避免重复创建。
4. 手动同步，或在问卷开放且页面可见时每60秒自动同步。也可先使用 JSON 导入和本地样例，无需金数据凭据。统计按各题有效回答计算，可查看原文并排除无效记录。
5. 按需关联音频转写或 PPT，和智能体讨论，生成整体总结与建议；可修订、确认、查看历史依据、回听和导出 Markdown。普通问候直接回复，分析任务可暂停与继续。
6. 编辑并勾选下一课建议，点击“按建议修改 → Sprint 1”。备课页展示来源并保留已有输入，由教师选择课件、确认和发送要求后执行修改。

导入默认限 UTF-8 `.json`、4 MiB、每课堂10000条、单条文本4000字符，先预览再确认；限制可通过环境变量调整。样例与正式反馈分开保存。截止后仍可补同步，达到截止时刻的反馈单列为晚到，缺少精确时区时间的单列待核对；远端是否已停止填写须在金数据核对。

已在专用测试问卷上验证真实创建、手机与桌面匿名填写、反馈更新、重复同步和到期停止收集，并使用真实模型测试合成课堂的综合诊断与建议交接。具体边界见[真实联调记录](docs/sprint3-live-validation.md)，操作和导入格式见[反馈说明](docs/feedback.md)。

## 数据与备份

配置、工作区、录音、模型及任务检查点保存在`data/`，导出文件在`output/`，测试产物在`artifacts/`。这些目录和`.env`均被Git忽略。

迁移电脑时，停止服务后自行备份`data/`；其中可能包含密钥和课堂资料，不应上传公共仓库。使用`.env`配置时还需备份该文件。清空课堂会删除录音、转写和报告，单独删除原音频会使相关片段失去回放能力。

停止服务使用`Ctrl+C`。重启后恢复已保存成果，支持检查点的未完成任务可以继续；正在录制但尚未保存的内容不能依靠重启恢复。
