# 示例代码分页与功能复核

2026-10-11。按教师最新要求，优先修复功能和讲课体验，暂缓课程算法与预期输出的正确性核验。

## 已实现的行为

- 示例代码有独立的源码字段、等宽预览与编辑框；源码中的缩进、空行、运算符、注释及尾部换行保留。代码不会在网页中执行。
- 分页先识别函数与完整代码部分，优先在一页放下一个或多个完整函数；识别时排除注释、字符串等内容中的括号。支持 C++/JavaScript 的常见括号结构及 Python 函数、装饰器与嵌套函数。
- 普通代码页按约 20 个显示行排版，稍长的完整函数可占到约 28 行，PPTX 相应调整字号。超过单页容量的函数优先在完整语句或控制块之后继续；识别不到合适边界时仍可能按行分页。默认备课提示词也要求使用短而完整的函数和辅助函数，长解释放入教师备注。
- 编辑一个代码分段后，会重新整理同一程序的分页；“复制完整代码”始终拼接该程序全部源码段，不把预期输出混进源码。Markdown 和原生 PPTX 使用同一份源码。
- 已保存的课件可展开“版本与更多导出方式”，点击“按函数整理代码分页”。这项操作不调用模型，有实际变化时保存新历史版本；再次整理相同结果不增加历史版本。旧版本、教师备注、预期输出、关联互动及无关页面保留。
- 修复浏览器 HTML 对 textarea 首行换行的处理，避免编辑框吞掉源码开头的空行；对 Windows 换行的显示差异单独判断，避免确认、导出、只改备注或语言时误改源码。草稿页保留代码缩进，手机上长行在代码框内横向滚动，教师备注正常换行。

这是结构识别和展示分页，不是完整的编程语言解析器；不能保证任何长度、任何语法的函数都在一页。很长的函数仍需要拆成完整部分或由教师调整实现。
