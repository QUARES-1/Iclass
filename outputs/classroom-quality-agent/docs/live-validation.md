## 教学资源

本轮编写的排序基础资料用于真实 DeepSeek 验证，没有将模型测试接口的返回作为真实结果。完成五页 PPT、指定第 3 页修改、人工备注保留、点击答题、冒泡拖拽、配对及步骤网页生成。四种互动均通过后端实际运行检查；Chrome 实际点击、全屏拖拽、提示、重置和离线 HTML 操作通过。

模型首次将 `action` 错写为 `type` 并漏掉 `reply`，接口拒绝候选且保留失败记录；增加明确顶层 JSON 示例后复测通过。内容复核还发现点击题答案索引与解释矛盾，及归并稳定性说明缺少相等时取左侧的条件。通过连续对话修正，保留原版本，并补充生成提示中的一致性要求。运行检查能验证交互执行，不证明所有学科结论正确；教师仍应复核内容。

PPT 配套 ZIP 内的互动 HTML 与所引用的修正版本快照逐字节一致。确认按钮由验收脚本操作以验证正式导出，不代表用户已批准教学内容。

## 完整课堂来源

[互联网档案馆北京大学计算机网络课程](https://archive.org/details/engineering6_computer_networking_course)，[公开元数据](https://archive.org/metadata/engineering6_computer_networking_course)，[第一讲原始文件](https://archive.org/download/engineering6_computer_networking_course/1.rm)。视频内有北京大学标识；原文件 GB18030 标签记载授课人为张进宇，标题为“网络的根本目的和基本特点”。

原始 RealMedia 文件为 57,099,747 字节。视频容器声明 2990.44 秒；逐帧解码的实际音轨从约 0.046 秒至 2975.847 秒，解码样本累计 2975.823 秒，无超过 50 毫秒的帧间间隔。全部音轨转换为单声道 16 kHz M4A，时长 **2975.848 秒（49 分 35.8 秒）**，18,953,549 字节。未剪裁课堂、拼接重复样本或加入合成语音。原媒体仅用于本机验收，未纳入源码版本控制。

旧文件标签不是 UTF-8，默认严格读取会失败。音频探测已允许替换无法解码的标签字符，分块转换剥离标签；保留非法标签的 3 秒 M4A 夹具探测通过。转换只处理容器/编码，不把视频入口加入产品。

证据：`artifacts/audio/classroom-source-metadata.json`、`classroom-source.json`、`legacy-metadata-result.json`，以及源视频首段、中段和末段画面。

使用 `scripts/review-classroom-samples.py` 将实际音轨在开头、中段、末尾和全部 16 个分块交界提取为 19 个独立 20 秒窗口，再用同一本地模型独立识别。结果包括原稿对应片段、独立窗口结果、时间和可回放 WAV，耗时 60.103 秒。开头的课程回忆、中段的两个房间与地址命名、末段的网络互联、中国网络发展及校园网，与源画面及独立窗口内容对应；未发现整块复制或大段内容丢失。

这不是逐字人工听校或准确率基准。窗口截断、繁简混用和同音误词导致文本相似度有差异，不能把相似度当正确率。实际原稿存在“地质”误作“地址”、“微信”误作“唯一性”、“China Night”、“SERNAT”等误词，以及少量交界词重复；不宣称所有句子准确。浏览器验收将地址语境的 4 个片段校正，原稿保留、时间及片段 ID 不变，刷新后校正版恢复。未确认的专名及其他误词仍应听原音频校正。

长文本实际分为 2 段分析。首次真实整课汇总触发模型输出长度上限，任务标为失败，没有保存不完整报告。已限制报告条目/代表证据数量，并仅向汇总提供各段结论、已引用证据和时间范围；完整片段覆盖仍单独保存。修复后真实模型调用约 35.116 秒完成，最终报告有 59 条：摘要、知识点、重点、观察、建议各 10 条，潜在难点 9 条。汇总遗漏整段主题时应用保留该段真实分析，因此最终条数可超过单次模型提示上限。两个分析段覆盖全部 845 个 ID，每条引用均有效，潜在难点均标记为推测。

证据 ID 存在不等于结论内容正确。复核发现模型将约 2.4 秒片段间隔写为“超过4秒”，将主题跨度当连续讲授，部分表述超出所引用片段，还有专名未经校正和历史课堂“现在”的语境问题。通过浏览器教师编辑入口修订 16 条，收窄引用范围、纠正计算、明确文本统计限制及历史语境，保存并刷新恢复。原始模型报告保留在 `classroom-analysis.json`；修改理由见 `classroom-report-review.json`。这次修订由 Codex 验收执行，不代表人工教师逐字听校或已批准全部教学结论。

Chrome 验证了六类报告、59 条显示、报告证据回放、内容修订、确认及 Markdown 导出。转写区域有独立滚动范围，长录音不会把报告控制埋在数百个片段下。完整服务重启前后，工作台和课堂 JSON 的 SHA-256 完全一致：5 份教学资源、识别原稿/校正版、1 份报告全部恢复。修订版 Markdown 为 `artifacts/live/classroom-reviewed-report.md`；确认动作仅用于验收正式状态，不代表教师批准。
