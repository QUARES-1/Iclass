# 数据空间、历史归档与草稿恢复

更新日期：2026-10-21。

在“模型与提示词设置”展开“数据与恢复”，可以刷新空间统计、清理无引用数据、归档较早历史、补回历史和删除归档。维护时要求没有正在执行或停止的任务，不会与上传、发布或分析同时改写资料。

## 空间与历史

- 本地业务数据默认额度为 **5 GiB**，环境变量 `DATA_MAX_BYTES` 可调整，重启生效。录音、业务记录、恢复副本和归档均计入，`data/models/` 模型权重不计入。
- 超额时拒绝新的写入或上传，保留原稿。减少占用的保存、清理及归档删除仍可执行，避免额度降低后无法释放空间。额度按文件逻辑大小统计，不等于文件系统可用容量。
- 清理会回收无引用任务、输入和资料快照、无引用录音、过期预览及旧临时文件，并压缩已删除课堂的本地残留；保留当前数据、暂停任务、恢复副本及归档所需引用。清空备课讨论后也会在空闲时尝试回收，上一份恢复副本仍引用的数据暂时保留。
- 归档默认每项保留近期20份历史，可设置2～200。当前版本、直接撤销目标、暂停任务的基准版本及课堂关联版本仍保留；当前校正所需的识别原稿另有固定关联，不会因历史链缩短而无法查看。
- 归档包括较早课件版本、讨论、转写、音频报告、反馈报告修订和模板版本。内容压缩保存至 `data/.archives/`，可以在设置页补回；重复归档没有变化时不再创建文件。
- 补回只合并缺失历史，保留当前版本与教师后续修改；重复补回不重复追加。输入已变化的旧报告仍标记历史/待更新，已删除录音不会因此显示成可用的新录音。
- 删除归档会永久失去尚未补回的归档历史，需要页面确认。归档仍引用的录音会保留；删除归档后再清理才能回收不再需要的录音。

归档保存业务记录，不打包录音二进制文件。迁移或离机备份请复制整个 `data/`，包括 `.archives/` 与 `.recovery/`，并保留所需 `.env`。单份归档展开上限256 MiB；超过时明确拒绝，当前记录不被裁剪。

## 保存与损坏恢复

每次成功写入采用临时文件与原子替换，保留上一份有效记录；首次保存也创建副本。恢复副本在 `data/.recovery/`，权限与业务文件同样受限，不由静态页面公开。

主记录缺失、JSON 损坏或根结构无效时，会尝试恢复副本，并提高修订号以拒绝恢复前的旧提交。页面提示已经恢复，需要教师核对内容；设置页可以查看并确认提示。损坏文件保留为每条记录一份 `.damaged`，便于排查。

主记录和副本均不可用时，返回明确错误，不能以空记录冒充恢复成功。已有历史归档时，可从设置页补回；缺失或损坏的业务记录可从归档恢复。恢复不保证拿回损坏前最后一次修改，自动副本也不等于离机备份。

存储读取有按文件身份校验的缓存：至多32条、按序列化大小估算16 MiB，超过2 MiB的单记录不常驻。保存减少重复序列化；备课输入仅复制当前资源版本和近期讨论，固定资料快照按内容复用，进度文件独立保存。状态未变化时，Sprint 2 轮询只传修订号结果。较大当前课件或转写仍需要载入内存，归档用于降低活动历史规模，未承诺任意大小都能即时处理。

## 浏览器草稿

备课标题、正文、代码、备注、教学要求、手动资料正文、未发送要求，以及 Sprint 2 的课程、转写校正、报告修订和未发送问题，缓存于当前浏览器的 IndexedDB；较小草稿另有同步恢复日志。

- 同一标签页且来源版本相同，刷新后恢复未保存编辑，仍需教师保存。
- 来源版本变化或发现其它标签页的草稿时，先显示恢复/下载/丢弃入口；当前已有新输入优先保留，不将旧片段校正套到新的录音片段。
- 两个标签页独立保存；成功保存和发送会更新或移除对应草稿，不在下次刷新复活。
- 设置页可以清除本浏览器的草稿缓存；其它仍打开的编辑页后续输入会再次缓存。

草稿不包含 API Key、问卷凭据、上传文件句柄和未保存录音。单份编辑草稿缓存上限约4 Mi字符，超过或浏览器存储不可用时明确提示手动保存。浏览器清理站点数据、隐私模式限制或设备损坏仍可能使草稿丢失。

## 状态轮询

Sprint 2 同时最多一个状态读取，15秒超时后中止并重试。页面离开或隐藏时中止读取；从浏览器缓存返回或重新可见时恢复。迟到响应须同时通过页面代次、输入版本和保存状态检查，避免回退界面。
