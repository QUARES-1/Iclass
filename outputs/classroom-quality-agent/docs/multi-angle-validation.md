# 并发、故障与交互恢复检查

2026-10-20。在此前重复操作检查之外，使用独立临时存储和浏览器夹具继续测试。没有使用正式课堂或真实服务商凭据，不产生在线模型调用费用。

| 角度 | 操作与原问题 | 修复或验证结果 |
| --- | --- | --- |
| 并发提交 | 同版本20次并发发送只接受一条，却产生20份任务及输入文件 | 在课堂版本检查通过后准备文件；只留下获准任务的文件 |
| 存储故障 | 模拟任务文件准备完成、课堂提交时发生磁盘写入失败 | 回收该任务及输入，原课堂没有半条消息；共享资料快照不盲目删除 |
| 取消释放 | 20个排队请求在前一个慢请求结束前取消 | 取消后立即拒绝并移出队列，不等待前面的请求；不调用已取消请求的服务函数 |
| 绑定一致性 | 等待远端表单读取时，另一个操作修改课堂 | 绑定失败不再抢占归属，另一课堂仍可绑定；发布仍在处理时拒绝同时手工绑定 |
| 分页失败 | 第一页成功、后续页失败 | 不提交前半批，原记录与业务版本不变；重试完整提交并保留本地反馈，再同步不重复 |
| 日期边界 | “2月30日”、非闰年2月29日或24点被自动归一化 | 按实际日历与时分秒校验；无效截止拒绝，截止统计中的无效提交时间单列待核对；合法闰日保留 |
| 异常输入 | 空值/数组等错误请求体、空建议项、重复建议标识、错误引用类型及混合失效的交接选择 | 返回明确4xx错误，原稿及修订号不变；不静默丢弃所选建议 |
| 导入一致性 | 教师改了导入文件的 `answers`，旧 `rawAnswers` 在修改截止后恢复旧答案 | 导入按文档字段 `answers` 建立原始快照，后续重算不倒退到旧内容 |
| 创建等待 | 新建课堂等待时仍能修改即将切走的原课堂；下一条新标题被清空 | 等待时保护原课堂编辑区；保留新输入的下一条标题，原课堂对话草稿可继续使用 |
| 保存重试 | 人工报告保存临时失败 | 草稿和版本保留，重试成功后只有一条实际修订 |
| 跨阶段恢复 | 建议载入失败需刷新；已输入但未再编辑的草稿未缓存；已发送要求刷新后复活 | 可原地重试，成功载入即保存现有草稿；成功发送后同步清空交接缓存，刷新不再恢复已发送内容 |
