# 生成中断与恢复

2026-10-11 检查本地状态：最新“平衡树”任务停在区间翻转步骤，连续出现 `MODEL_FORMAT`，保留了53页草稿。另一旧任务在自动检查后反复返回相同补丁，保留了87页草稿；该任务要求添加的左右子节点判空条件在当前草稿中已经存在。

历史任务未保存原始模型响应，不能断言那次格式失败的具体语法原因。代码检查确认并复现了如下应用缺陷，现已修复：

- JSON 解析先读取完整响应，避免将合法字符串里的 Markdown 围栏误当成外层围栏。只规范字符串中的原始控制字符，保留源码；不猜测缺失引号、字段和结束括号，拒绝截断响应与顶层数组。
- 格式错误给出 JSON 转义反馈，不自动按输出过长拆散逻辑单元；只有真实输出超限或超出批次容量才减小批次。记录响应长度、结束原因和错误类型，不保存或回显模型原文与凭据。
- 自动修正的相同补丁不重复写入、不反复重试，返回独立内容检查。只有新的检查通过后才提交；仍未解决的问题受修正轮次约束，草稿保留。教师普通修改的相同补丁仍明确提示未形成修改。
- 内容检查优先验收功能。未独立运行的算法正确性、复杂度、代码边界和预期输出疑点列为建议，不据此强制改写算法；真正的编译/运行失败、核心内容缺失、范围与结构错误仍须修正。没有运行证据不声称代码或算法已验证。

本次改动不自动重写、合并或发布教师现有课件，不修改教师保存的任务与历史。失败任务可从“继续任务”恢复，沿用已有草稿。

验证：`npm test`。`test/model-format.test.js` 覆盖围栏、源码换行、非法转义、截断、数组和安全诊断；`test/agent.test.js` 覆盖格式重试、相同补丁重新检查及检查仍失败时不得提交。真实模型功能验证脚本 `scripts/verify-model-format-live.mjs` 只发送构造的教学内容和默认策略，不发送教师资料或自定义提示词，不作为算法正确性验证。
