# 自主备课与界面调整

2026-10-11，依据 req.md / plan.md v1.3 追加需求。

后续对话入口与当前功能验证以 [对话与自主工具选择](conversation-agent.md) 为准：205 项单元/接口及 40 条浏览器流程通过。规划已成为复杂任务的可选执行方式，普通聊天直接回答，简单修改直接调用工具。课程算法核验按教师要求暂缓，下文的流程、轮次、页数与测试数量保留为此前验证记录。

备课工作台现在使用持久化智能体任务，而不是等待一次整份 JSON 输出：规划教学目标与课时 → 按主题检索资料 → 按计划调用 PPT/互动生成、更新和关联工具 → 记录结果 → 检查全部实际内容 → 执行修正 → 原子提交新版本。工具调用由模型计划决定；数据结构、修改范围、活动运行、版本冲突和预算由后端检查。

每批默认 3 个逻辑页面，任务默认最多 120 次模型调用、60 个计划步骤、3 轮修正。所有额度、智能体策略提示词、API 地址/模型/密钥及原有业务提示词都可以在设置页调整。没有总页数业务上限；单次输出超限自动缩小批次。修正次数有限，检查仍未通过时保留真实草稿和原因，不提交不完整成功。

计划与每批草稿保存在后端 `data/agent-任务ID.json`，文件权限 0600；不保存 API Key。公开进度接口不返回输入资料或草稿正文，专用草稿接口只返回当前生成资源。“查看任务草稿”在独立页面供检查及 Markdown 草稿下载，不提供确认或写入操作。暂停、刷新、重启后可从检查点继续，恢复使用最新模型配置；改变教学要求、资料或目标版本后拒绝覆盖。

首页重新使用统一样式与清晰设置入口。工作台保留常用操作，版本/导出选项、文件限制、长修改记录收进折叠区；提供页面定位，减少彩色块与重复元信息。草稿页面的普通长文本按手机宽度换行，示例源码保留缩进并在代码框内滚动。

验证：单元与接口测试覆盖规划课时、真实工具循环、超限拆批、分段检查、实际修正范围、备注保护、多资源固定版本、暂停/恢复、重启、预算与冲突；浏览器模拟覆盖自主任务、暂停刷新恢复、只读草稿、首页及原有上传/编辑/确认/导出/音频功能。浏览器的模型为明确的接口夹具，不替代真实教学质量检查。最新完整回归：165/165 项单元与接口测试、32/32 条 Chrome 浏览器流程通过。真实课程结果见 `artifacts/agent/live-result.json`，短课程隔离测试见 `artifacts/agent/small-live-result.json`。

真实长课件复测已暴露并修复：多段检查重复修正ID、修正页数少于目标数、生成备注被错误保留、只新增正确页面却不修正错误原页，以及手机长代码溢出。原课件和课堂数据保留，执行失败期间可检查任务草稿；不把草稿页数增长标记为内容验收通过。

检查将已核实的知识、计算、答案错误及核心任务缺失列为必须修正；章节标签、可选扩展等建议单独展示，不触发反复润色。模型自检不是独立的人类教学质量审查，仍可能误判或漏判，教师保留审阅与最终确认权。

真实长课件：现有 300 分钟数据结构课程按六个章节自主规划，累计完成 76 批生成与修正、3 轮修正，得到 308 页实际展示草稿，最终复核累计 119 次模型调用，仍有 18 项待处理问题。仍未通过内容检查，未提交为正式资源；原 14 页、两个历史版本、资料、教学要求与课堂记录保持不变。草稿可在任务面板查看或下载；页数增长不代表教学质量验收通过。

短课程真实模型复测曾在 35 次调用、3 轮修正后仍发现反例矛盾（66 页草稿），拒绝提交。记录保留在 `artifacts/agent/small-live-result-before-context-fix.json`。据此增加相邻页只读正文上下文，并要求修正仅处理本页承载步骤，避免续页反复复制整段演算；再次隔离验证使用明确且人工核算的教材与循环边界。

相邻页上下文补充后，短课程收敛到 17 页，但模型检查把已经独立核算正确的步骤再次列为错误。增加“已排除问题不得列入缺陷”的一致性校验与重核反馈，避免模型自相矛盾触发无谓修正。该检查只拦截明确矛盾，不能代替教学事实审查。

最后一轮隔离短课复测：16 次真实模型调用、7 批执行、3 轮修正后仍有核心循环规则覆盖与变体演算待处理，任务失败且未提交资源，真实模型完整成功路径本轮没有通过，不能用自动回归替代此结果。该轮证据为 `artifacts/agent/small-live-result.json` 与 `small-live-draft.json`，先前 17 页检查误判证据保留为 `small-live-result-context-only.json`。

当前限制：自主规划与工具执行、暂停恢复及保护旧数据均已验证；长课程与算法课的模型生成/自检仍可能反复修正和误判，不能保证任意课程自动通过内容检查。教师可配置模型与策略、查看失败草稿，正式成果仍需教师确认。本轮不把这些课程标记为验收通过。
