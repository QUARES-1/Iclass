# 教师可配置模型与提示词

2026-10-11。用户反馈：课件总量、教学深度写在程序内部，教师无法修改模型、密钥和系统提示词；详细扩写被排版校验拒绝。

原工作空间设为数据结构、本科二年级、300 分钟，当前课件为 14 页、2 个版本。原默认提示词却要求“先生成不超过15页”；后续扩写出现“修改后页面内容过长，请拆为新页面后重试。”这属于实现缺陷，不是教师要求不合法。

## 现在的行为

首页、备课工作台、课堂复盘提供“模型与提示词设置”。工作台与复盘在新标签页打开设置，避免导航丢失正在编辑的内容。

- 配置 API 基础地址、模型名称、API Key、温度、最大输出 token、请求超时与最大输入字符数。使用 Chat Completions 兼容接口；基础地址支持 `/v1`，完整 `/chat/completions` 地址自动规范化。
- 编辑备课对话、资料理解、课堂复盘和兼容旧版大纲接口的程序提示词。可以恢复某一提示词默认值，保存后用于下一次请求，无需重启。已发起任务保留配置快照。
- 教学策略与应用输出结构协议分开。教师可改变教学深度、页数与练习安排；JSON、稳定页面 ID 和证据引用等结构约束仍由程序验证。设置页可查看备课和复盘协议。
- 单次输出额度可调整，不再存在课件 15 页或 150 页的业务上限。详细扩写在保存前自动分页；新增主题页可指定原页之后的插入位置。原页首段保留 ID，续页获得新 ID，未涉及页面的内容和确认状态保留。备注保留，固定互动入口保留在原页。
- 手动编辑同样自动分页，并清理已经保存的长正文草稿；保存时继续输入的其他新草稿保留。预览、确认、Markdown 和 PPTX 均使用已保存的真实页码。
- 资料理解在设置额度内使用完整已解析正文；超额时不向模型发送截断正文，返回带原因标识的本地规则解析。教师自定义提示词要求更多知识条目时，不再暗中裁切为固定 20 条。

密钥存于 `data/model-settings.json`，文件权限 0600，目录已被 Git 忽略，静态服务拒绝读取。配置 API 仅返回是否配置密钥；输入留空保留、输入新值替换、显式勾选清除会持久禁用密钥，即使 `.env` 仍有旧值。密钥不进入工作空间、录音记录或导出。多标签页保存检查独立配置版本，冲突不覆盖输入。首次未保存配置时继承 `.env`，之后教师保存的配置优先；清空教学数据不会清空模型配置。

“测试当前连接”使用当前表单值发起一次简短真实模型请求，不自动保存配置。测试与配置写入也受外部来源检查；连接测试使用模型调用频率限制。

## 实测

`npm test` 147/147；Chrome 自动交互 29/29。新增检查涵盖持久恢复、私有文件拦截、密钥保留/替换/清除、配置冲突、输入额度、完整长资料、各模型调用传参、定向分页和确认保留。浏览器实际保存与恢复设置、连接测试不自动保存、手机宽度长提示词保存，以及 13 条正文拆成 4 页后导出的 PPTX 实际总页数为 6。

正式设置页真实连接 DeepSeek 成功；另一真实请求使用自定义教师提示词在内存中生成 18 页，验证不受原 15 页限制。生成结果只写测试产物，未替换现有课件。工作空间与课堂记录测试前后 SHA-256 相同。原始记录：`artifacts/model-settings/live-results.json`、`real-model-candidate.json`、桌面/手机截图；自动测试日志同目录。

当前原课件仍为 14 页、2 个版本；修复不会自动把既有提纲改写为 300 分钟课程。教师可先调整提示词，再重试生成或按章节扩写。18 页测试证明接口与配置生效，不作为完整长课的教学质量验收。

总页数不受上述业务上限约束，单次请求仍受服务商上下文与输出 token、所设超时、JSON 格式、请求体和单记录 100 MiB 存储上限约束。提高表单输出额度不能突破模型服务商限制；长课程仍可按章节生成。现阶段没有自动将一次长课需求规划为多轮生成任务。

## 配置接口

`GET /api/model-settings` 获取脱敏配置与版本；`POST /api/model-settings` 保存可修改字段和 `revision`；`POST /api/model-settings/test` 测试当前字段、不保存。密钥字段 `apiKey` 留空保留，`clearApiKey:true` 清除，两者不能同时指定替换与清除。测试和保存的 `revision` 必须为读取配置时的版本。
