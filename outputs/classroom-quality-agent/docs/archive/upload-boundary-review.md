## 文件要求与明确限制

| 输入 | 接受条件 | 限制与处理 |
| --- | --- | --- |
| TXT / MD | 有有效正文的 UTF-8 文本，支持 BOM、大小写扩展名 | 原始文件 ≤15 MiB；拒绝不合法 UTF-8 和二进制控制字符，包括被截取正文之后的控制字符；空文件/全空白拒绝 |
| DOCX | ZIP 格式的未加密 Office 文档，包含可提取正文 | 原始文件 ≤15 MiB；正文 XML 单条 ≤5 MiB；提取段落文字、换行和制表符；图片文字不做 OCR |
| PPTX | ZIP 格式的未加密 Office 文档，包含带文字的幻灯片 | 原始文件 ≤15 MiB；单页 XML ≤5 MiB、所选幻灯片 XML 合计 ≤30 MiB；最多 5000 个 ZIP 条目；不支持分卷/ZIP64/其他压缩方法；按页号提取 |
| 旧 DOC / PPT、PDF 等 | 不接受 | 前端说明另存为 DOCX/PPTX；后端仍独立拒绝，不能靠改名转换格式 |
| 所有教学资料 | 文件名 1～255 字符，粘贴资料也适用正文限制 | 最多 20 条，失败记录也占名额；一份最多保留 250000 个 UTF-16 字符单位、合计 ≤500000。文件自动截取时保存原长度和提示；粘贴超过上限则拒绝。截取不留下破损的 emoji 代理字符 |
| WAV / MP3 / M4A / WebM / OGG | 实际容器与扩展名匹配；存在可解码音频帧；拒绝真实视频轨 | 默认 ≤512 MiB、≤10800 秒。可通过 `AUDIO_MAX_BYTES` / `AUDIO_MAX_SECONDS` 配置，页面读取后端实际限制；无效配置回退默认值。允许音频中的封面图片轨 |
| 浏览器录音 | 浏览器支持的 MediaRecorder 格式 | 开始前请求权限；录制中不转写；达到时长或接近字节限制自动停止。停止后可以回放、保存、重新录制或放弃；保存后才允许转写 |

MiB 为 1024² 字节；“字符”当前沿用 JavaScript 字符串长度，不代表 UTF-8 字节数或自然语言字数。后端校验实际字节，前端 `accept` 和预检只是提前反馈。

Office 校验包括 ZIP 中央/本地条目一致、实际解压尺寸、正文 CRC、重复条目/页号、加密标记、UTF-8 和危险 XML 实体声明。不声称完成 Office 全文档模式校验；未使用的图片等附属条目也没有全部解压校验。

音频探测检查容器、音轨、时长和首个可解码音频帧。没有在上传阶段解码整段音频；后续损坏仍可能在转换/识别阶段报错。没有语音的可解码录音可以保存，在真实转写时会明确返回“未识别到语音”。

## 文件可保存与 AI 可使用的范围

- 文件正文保留上限和模型上下文不是同一限制。页面在资料较长时提前提示。
- “理解资料”的 AI 输入对单份选取最多 50000、合计最多 100000 字符；过长时保留首尾、标出省略，并将警告随结果保存。规则回退仍标注“非 AI”；特别长的结构化条目会缩略并提示，避免理解结果无法再次保存。
- 资源对话需要完整当前资料、资源和相关上下文，默认输入额度为 115000 字符，现可在“模型与提示词设置”中调整；超限明确说明，不静默丢弃资料。资料保存成功不保证任意数量资料都能一次交给模型。
- 课堂分析按正文与序列化预算分段，保留所有合法片段及证据 ID。原有 845 段校正版两次分析实际请求为 109002 / 42951 字符，全部片段覆盖。

## 本轮修复

| 问题 | 修复后的行为及验证 |
| --- | --- |
| 超长资料截取标记使正文超过后续限制 | 正文保持在 250000 内；截取信息独立持久化，刷新后仍显示；长资料可以进入理解流程 |
| 中文 JSON 网络分片产生乱码或错误长度 | 收齐受限字节后严格 UTF-8 解码；强制在一个汉字内部拆包，250000 字符用例通过，理解结果无替换字符 |
| 超长规则理解条目无法保存 | 结构化条目限制与后续接口统一，并明确提示缩略；AI 选材省略也显式记录 |
| 文本伪装二进制、Office 损坏和虚报尺寸漏检 | 拒绝控制字符、非法字符实体、加密/重复条目、正文尺寸与 CRC 不符；解压和整体大小独立限制 |
| Office 行内换行消失 | DOCX/PPTX 保留正文换行与制表符，避免知识点直接粘连 |
| 文件要求不清、超额批量才逐个失败 | 上传前展示格式、编码、大小、数量；整批超过剩余名额时不发出上传请求；混合批次继续处理正常文件，逐项展示错误 |
| 音频过大请求断连接、扩展名伪装 | 超量流保持磁盘受限并返回明确 413；实际容器与扩展名一致才保存，真实 WAV 改为 MP3 被拒绝 |
| 上传无等待/取消入口，坏文件无法立即重选 | 音频显示真实传送进度和服务端检查阶段，可取消；资料批次可停止；结束后清空文件选择器，同一坏文件可再次选择 |
| 取消/并行课程保存造成错误覆盖 | 取消时清理未提交文件；上传检查期间课程保存不丢失，新音频也能正常提交。若取消时服务器已提交，刷新显示实际保存状态，不宣称撤销了已保存录音 |
| 录音停止后无法改用文件；权限等待可重复启动 | 增加“放弃未保存录音”；权限等待期间锁住再次启动和上传。模拟 Chrome 设备完整验证，未使用物理麦克风 |
| 无关保存重置正在试玩的小游戏 | 未改变互动版本时保留 iframe、答题反馈和运行状态；显式“重新试玩”仍可以重置 |
| 新预览刚切换时首次点击无反馈 | 切换期间显示等待并阻止旧预览接收鼠标；新 iframe 完成加载、运行器就绪和布局后才显示可交互状态；重复 8 次通过 |
| 请求期间继续输入的文字丢失 | 按服务端实际保存内容清除对应草稿，后续输入保留；展开状态、输入焦点、光标和滚动位置恢复。AI 返回也保留等待时输入的下一条要求 |
| 追加编辑后仍确认旧内容 | 确认/导出保存期间又出现编辑时保留草稿并阻止操作，要求保存后重试 |
| 草稿导致完成报告不显示 | 任务进度更新可以刷新报告并恢复课程草稿/焦点；分析运行期间锁定旧报告修订，避免修订属于已经切换的报告 |
| 资料理解期间移除输入却保存旧结果 | 在串行提交前比较本次理解的输入；资料变化时不应用旧结果，提示重新理解；验证删除请求尚未返回时理解已完成的交错情形 |
| 载入示例绕过资料总量或沿用旧理解 | 示例入口也验证合计 500000 字符；超量不修改任何已有数据，成功加入新资料则清空旧理解并提示重新理解 |
| 保存时间刷新丢失，配置读取失败误报恢复失败 | 保存时间随课堂数据迁移保留；配置读取失败独立提示，不把已恢复的数据显示为恢复失败 |

## 实际交互模拟

1. 桌面：上传有效资料与坏文件，查看正文/失败原因，理解并核对来源；生成 PPT，编辑教师备注，等待保存时继续输入，验证草稿/光标/展开状态；确认并检查正式导出，再刷新恢复。
2. 互动：选小游戏、答题取得正确反馈，保存课程要求而不中断试玩；切换与重新试玩、拖拽/按钮排序、配对、步骤推进、全屏、离线导出继续复测。
3. 手机宽度 390×844：通过“资料与资源→连续对话→预览与编辑”标签完成上传、理解、生成、编辑、确认、PPTX 下载；检查页面没有横向溢出。截图 `artifacts/boundaries/mobile-edit.png` 已查看。桌面浏览器缩窄视口不等同于真实手机或系统软键盘验证。
4. 音频：上传 WAV、看到检查状态、取消新上传并检查原录音仍在、同一坏文件连续选择两次；另验证扩展名伪装。请求权限时等待、停止录音、放弃未保存录音、再上传文件；执行真实识别、校正、证据回放、分析、报告修订/确认/下载/刷新。
5. 正式真实课堂：只读复查既有完整课堂，三个时间位置回放正常，报告和原稿对应，重启后数据哈希不变。

## 剩余验证与范围

需求仍为 23 项有实现、20 项在已记录的本机流程/样例通过、3 项部分验证：S2-01 未做物理麦克风；S2-05 未完成长课堂人工听校；S2-07 已新增真实任务时限终止，但真实内存/显存不足未测。不得把自动全部通过或一次课堂演示等同于所有场景的最终验收。

浏览器实现仅实测本机 Chrome；真实移动设备、Safari、GPU、其他电脑和 512 MiB/3 小时极限录音尚未实测。大小精确边界使用配置的 64/65 字节接口用例与实际 15 MiB+1 前端文件预检验证，不把缩小限制的用例说成已经上传了 512 MiB 文件。文件上传后的任意操作竞争仍受 revision 检查保护；AI 请求期间改变资源/资料会明确拒绝覆盖，需重新发送。
