# 课件标题整理

2026-10-12。修复整体二分课件反复使用章节名称、自动分页叠加“（续2）”等后缀的问题。

## 行为

生成提示词要求页面对应具体知识点、函数或操作环节，章节名称用于章节引入，并跨批次核对已有目录。默认提示词和本机已保存的 agent、preparation、outline 提示词都补入该约束；教师原有提示词保留。

普通解释页分页时根据首条要点命名后续页；代码页根据函数名、结构体或输入输出等内容命名。函数识别先屏蔽注释和字符串，不执行或改写源码。移除末尾自动生成的“续N”“代码N/M”标记，保留数学括号、语言标记和教师的章节编号。教师明确指定且无需拆分的独立代码页标题保留。代码分页编号在小字号代码说明中显示，避免占据大标题。

新增内部工作台命令 `editSlideTitles`，支持一次版本保存批量标题变更，不触发重新分页；稳定页 ID、正文、备注和代码保留，无关确认状态保留。标题目标越界、重复、为空或超过长度限制时整批拒绝。可选合并只允许同一分页来源、所有非标题内容完全一致且无代码或附件的普通页面；不能借该命令删除非重复内容。版本可撤销。

## 本机课件与验证

整体二分原课件 91 页，其中 65 个标题带自动分页标记，16 次标题重复。整理后 90 页、90 个不同标题、零自动后缀。仅合并原第 76 页：其正文与前一页完全重复，备注及其余内容也一致，且两页属于同一分页来源。其余页顺序、ID、正文、备注、源码、输出与关联不变，平衡树资源及交互记录保留。

完整回归：235/235 项单元及接口测试、42/42 条 Chrome 浏览器流程通过。标题专项检查数学括号保留、注释及字符串屏蔽、教师标题保留、批量保存与撤销、非法目标原子拒绝、重复内容合并和旧标题导出兼容。

实际导出 `output/整体二分-标题整理版-草稿.pptx` 为 90 页，解包后逐页检查标题、正文及 40 张代码/文本记录页。源码从 Consolas 文本框的 XML 段落重建后，与导出模型一致（只忽略末尾换行）；正文标签移到独立形状时不把冒号分隔符计为内容缺失。宋体与 Consolas 字体设置保留。页面尚未由教师确认，导出仍为草稿。

本机证据位于忽略版本控制的 `artifacts/slide-titles/`：`applied.json` 记录版本变更及内容保留，`export-verification.json` 记录实际导出核对。该验证检查应用和展示功能，不替代课程算法正确性审核；自动命名和提示词也不保证任意模型生成的所有页面都不重复。
