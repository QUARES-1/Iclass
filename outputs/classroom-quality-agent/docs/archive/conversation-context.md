# 清空对话上下文

2026-10-11。

对话区右上角新增“清空上下文”。确认后清除全部历史交互记录和后续规划使用的对话上下文，收起旧任务面板；刷新页面不会恢复旧记录。课件、小游戏、网页、资源历史版本、资料、教学要求、知识点、模型设置和课堂复盘均保留。当前输入的新要求及未保存页面编辑也保留在页面中。

执行中的任务需要先暂停。暂停后清空意味着结束这一段对话，旧任务不能再继续，教师可以提出新要求。后端任务草稿快照保留，避免误删尚未提交的成果；它们不会成为新任务的对话上下文。清空历史对话不能在界面中撤销，取消确认则不改变任何数据。

实现使用带工作空间 revision 的 `clearConversation` 命令。后端拒绝执行中清空及过期版本请求，防止跨页面误删新对话；清空成功后停止旧任务进度轮询，避免旧状态重新显示。该操作不会调用模型。

验证：190/190 项单元与接口测试、36/36 条 Chrome 流程通过。新增检查覆盖真实持久化、后续模型规划输入不含旧对话、资源及独立课堂/模型配置保留、过期 revision、执行中拒绝、暂停后清空及旧任务恢复被拒绝；浏览器模拟取消/确认、未保存编辑保留、刷新、重新对话、手机入口和任务面板收起。
