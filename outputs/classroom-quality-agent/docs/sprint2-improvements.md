| 跨分段间隔遗漏、时间依据不清 | 传入边界片段与间隔；时间估算提供起止ID，后端计算跨度，页面与导出保留依据。 |
| 无依据学生结论通过 | 扩充禁止推断校验；有效ID仍不能保证语义正确，教师需核对证据。 |
| 暂停、取消、继续缺失 | ASR逐块写检查点，分析逐段保存局部结果；继续时跳过完成部分，最终整课汇总完成后才提交报告。 |
| 历史不可选 | 切换录音、恢复转写、恢复报告及人工修订前版本；删除过的原音频不会被恢复。 |
| 长转写难校正 | 每组60片段、搜索、时间定位、排除误识别；跨页编辑保留，原稿与时间不变。 |
| 页面操作不便 | 固定底部播放器，旧任务折叠，任务显示日期和录音名；手机优先显示报告。 |
| 总览过短、默认内容零散 | 一个总结条目可含2～3自然段，长课堂通常400～700字、建议1000字符内；建议按课堂实际需要展开，细分按需；支持整体确认。 |
| 无复盘对话 | 问答、读取转写证据、调整已有措辞、请求单类分析；问候直接回答；清空上下文后丢弃在途旧回复。 |

## 总结失败与完整转写补充

后续任务在两段分析完成后因整课输出的篇幅/条数校验失败。调整为明确反馈实际长度或数量并请求精简；已有候选完整且通过证据校验时，精简超时或合理篇幅偏差不丢弃候选。总览多个自然段合为一个条目，原先建议保留前三项，后续已取消该裁剪；缺少原文证据、无有效总结及安全保存上限仍受校验。

新增完整转写全文、时间显示、校正版/原稿切换与TXT导出，全文不受片段分页或搜索影响；导出先保存校正。当前845片段已本地导出为普通版和含时间版，没有修改课堂状态或重跑ASR。256项单元/接口测试及13项音频浏览器回归通过。

## 中文字形规范

原实现仅指定Whisper中文语言，直接保存输出，未区分简繁字形。新增本地OpenCC（opencc-js 1.4.2）转换：识别原稿单独保留，存在繁体时生成简体转写并作为当前版本。已有教师校正版也可生成独立简体版，ID、时间、排除状态及英文代码片段保留。纯字形转换对应的当前有效报告生成简体副本并保留全部证据、确认及原报告；过期报告不会被重新标为有效。261项单元/接口测试和14项音频浏览器回归通过。

## 改进建议展开

按教师反馈取消建议最多3条、每条80～160字/240字的提示词限制，不再裁剪前三条，也不因建议字数触发精简请求。建议按实际课堂问题展开理由和具体做法，合并重复内容；整体总结仍统一展示，细分分类按需生成。更新当前教师设置中的默认旧规则，保留其它提示词及32768输出额度。263项单元/接口测试、10项音频交互回归通过；7条超过240字的建议在生成、保存、刷新及Markdown导出中完整保留。

## 提示词整理

删除已保存课堂提示词中由程序添加的版本替代和配置更新说明，保留当前总结、建议要求与教师原有指令。变更经过只写在文档中，不发送给模型。课堂提示词负责教学分析策略，应用协议只说明当前JSON格式、分析范围与证据字段，避免重复附加总结和建议策略。263项单元与接口回归通过。
