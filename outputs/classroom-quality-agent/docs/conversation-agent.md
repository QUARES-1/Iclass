# 对话与自主工具选择

2026-10-11。此前入口把每条消息交给备课规划，导致“你好”也生成长课程计划。本次将入口改为模型自主选择回应方式，界面按教师要求保持简洁。

每轮使用同一个决策循环，模型可以直接回答、提出澄清问题、调用只读工具、提交简单操作，或选择复杂任务计划。没有问候关键词规则，也没有先强制执行一个独立分类器。只读结果和错误返回给模型，它继续决定下一步。为兼容当前模型连接，工具使用应用 JSON 协议，由后端执行；未调用供应商原生 tools 接口。

只读工具包括 `workspace.read`、`resource.read`、`material.read`、`context.read`、`conversation.read`、`task.status`。页面按稳定 ID 读取，资料按字符位置分段读取，不以文件路径访问；读取结果受输入额度限制。任务状态来自实时持久化记录，连续聊天多轮也不会把仍在执行的任务挤出查询结果。

问候、讨论和建议只保存对话，不创建计划、草稿或资源版本。明确的小修改直接进入已有工具执行器，保留页面范围、结构、版本、代码语法及互动运行检查；只核对本次操作，不要求修改标题也重新安排整堂课程。复杂任务仍可自主规划、分批执行、自检、修正、暂停及恢复，失败时保留真实草稿。旧版尚无执行批次或草稿的任务，在教师明确点击继续时重新理解原消息，避免误触发的问候计划继续生成课件；不会自动恢复旧任务。

后台任务执行期间可以继续聊天和查询进度。新的写入任务必须取得工作空间执行权，不能同时写入，也不会自行暂停或恢复旧任务。对话答复不因期间教师修改资料或课件而误判为覆盖冲突；真正的资源提交仍检查原始输入和版本。切换到后台执行后会先同步工作空间版本，再开放下一轮输入。

输入框改为“和智能体对话”和“发送”。普通回应只显示聊天记录中的等待提示和回复；已完成任务在继续聊天时收起进度。正在执行或需要恢复的任务保留简短状态和控制入口，计划、执行记录、检查结果默认折叠。操作对象与页面范围也默认折叠，没有选中资源时隐藏。刷新会恢复对话及后台任务的观察，不重复执行。

验证：218/218 项单元及接口测试、42/42 条 Chrome 浏览器流程通过。包括无效页码出现在问题里、只读范围与大小校验、直接修改越界、额度耗尽、教师并行编辑、连续十轮聊天后查询后台进度、新写入竞争、暂停恢复、刷新以及手机布局。浏览器接口夹具只用于功能验证。

真实模型在临时工作空间完成了五类验证：问候、概念解释、澄清、读取页面后解释、直接修改标题。问候只调用一次模型，未产生计划或草稿；标题修改直接执行并检查，只产生一个新版本。证据在 `artifacts/conversation/live-result.json`，手机交互截图在同目录。

自动审批拒绝了将教师现有资料及历史上下文发送给外部模型实测，故真实模型验证只使用构造的测试资料、测试历史、两页测试课件和应用默认提示词；连接使用教师已配置的服务，未发送教师教学数据或自定义提示词。没有恢复原暂停任务或把旧失败草稿提交为正式成果。本次验证不代替课程教学质量或算法正确性审查。

复测命令：`npm test`、`npm run test:browser`；真实模型的构造数据验证：`node scripts/verify-conversation-live.mjs`。

后续边界修复见 [功能边界与精简课堂评价](edge-fixes-and-review.md)：教师修订和已选补充传入模型，支持多页范围和指定页关联；明确的多页补丁自动拆批，不要求额外模型规划。长历史使用标明缩略的预览，可按消息 ID 补读全文；完整持久化记录不会被截断。
