- 转写、三页 PPT 以及12秒静音回放文件为构造夹具；本次不以这些结果证明真实录音识别准确率。

## 长内容与失败恢复

使用6段、共 **29779字符** 的合成转写，配合问卷和三页课件。它用于验证数据完整覆盖与恢复，不作为真实课堂的内容评价。

在 **20000字符输入窗口** 下，任务分成3批完成，经过暂停、并发问候和恢复后形成完整报告，任务记录为9次调用尝试，其中1次在发送前被输入额度校验拦截。恢复复用全部已保存分段与汇总结果，最终仅补完答复，没有重复提交报告。任务保持原模型、教师提示词和输入额度，检查点不包含 API Key。证据为 `long-result.json`。

另外保留了 **10000字符窗口** 的边界用例：7批均完成，但多轮汇总仍无法容纳全部中间结论，系统明确提示提高输入额度并保留分段/汇总检查点，未将该任务标为完成。修复期间，该隔离任务的测试调用预算由25扩至40，模型和教师提示词未变；预算耗尽同样保留成果。该用例不计入“完整报告成功”，也不代表产品界面支持修改旧任务的预算。教师主工作区的115000字符配置保持原值。

## 本轮修复

1. **真实服务商结构**：创建请求使用 `value/api_code`，读取定义返回 `name/value`；反馈返回中文选项和字符串评分。增加双向映射与数字规范化，并用真实形状更新浏览器夹具。依据：[字段定义](https://open.jinshuju.net/api_v1/schemas/field/)、[数据读取](https://open.jinshuju.net/api_v1/endpoints/get_form_entries/)。
2. **建议版本**：记录同一智能体任务自己的保存版本，允许继续完善；教师并发修订仍受版本保护，写入保持幂等。
3. **长内容汇总**：明确分段范围、改进引用修正提示、保存每组汇总检查点；聚合输入用紧凑结构和短证据标识，提交前恢复并校验原始引用。极小窗口无法完成时保留成果并提示调整。
4. **决策上下文**：工具读取按完整条目分页，超限的旧工具结果明确保留索引，不反复把长原文塞入最终答复请求；完整原文和已生成报告仍留在存储中。
5. **保存竞态**：报告及建议使用各自版本校验；后台回复只改变课堂总修订号时，教师仍可保存，真实同字段冲突继续拒绝。

## 追加多轮检查

追加浏览器延迟请求、并发服务调用与真实模型连续修订测试。先复现错误再修复，覆盖：

- 保存课堂信息等待期间修改截止时间或模板，全部字段参与草稿判断；迟到的后台读取不回退较新课堂版本。
- 确认报告或携带建议等待期间继续输入时保留编辑，停止后续确认或导航；查看依据跟随正在编辑的报告。
- 对话草稿按课堂暂存；切换时清除导入预览、搜索与音频状态。四个并发示例载入请求只产生一组课堂。
- 已完成、已取消任务不会被迟到的暂停请求改回可恢复状态。跨课堂预览、任务及报告不能串用；错误报告引用，以及原本没有音频的历史报告，均不会回退播放当前课堂后来关联的录音。中文选项可搜索。
- 同一智能体任务读取自己刚写入的报告，并选中最终候选；教师在期间保存的文字仍保留。写入结构及引用错误在执行前反馈模型修正，缺少数组不能隐式清空建议。

真实模型补测最初遇到候选引用只出现在正文、未填入 `evidenceIds` 的失败，原成果保留。补充工具契约并前移候选校验后，新任务用2次模型调用完成“保存初版 → 读取初版 → 保存完善稿 → 答复”，随后2次调用读取最终稿并回答，最终候选选择正确，没有新增远端问卷或修改课件。证据为 `extra-round-result.json`；失败任务也保留，不将其计作成功。自动校验修正另由工具调用和计划两类夹具覆盖。

浏览器重复执行也暴露出测试夹具共享模板及同名课堂选择的依赖，已改为每例明确原始模板并按课堂 ID 定位。最终数量、两轮重复及全量结果见 [testing.md](testing.md)。
