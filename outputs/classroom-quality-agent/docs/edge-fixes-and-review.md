# 功能边界修复与精简课堂评价

2026-10-11。复核发现的五项问题均已补充回归并修复：

- 教师修订的分析、知识点与选中补充进入决定、执行及检查上下文；较大内容标明预览，可用 `context.read` 补读原记录。
- 指定 PPT 页可以关联互动；实际关联页仍必须处于授权范围。选中小游戏时，范围绑定实际 PPT。依据某页新建独立小游戏不会被误当成修改原课件。
- 识别多处页码、列表和连续范围（如第2页和第3页、第2、3页、第2至5页）；每批只允许修改其目标页面，保留其它页。
- 局部字段和批量标题修改无需重新分配整课课时；新建完整课程仍校验课时。模型直接返回的多个独立页面补丁由执行器自动拆批，不增加规划请求；全部通过后一次提交新版本。
- 历史上下文按字符预算提供缩略预览，最新请求保留完整；`conversation.read` 可读取消息目录与原文，资源目录也可分页读取。存储中的完整历史不变。输入确实无法容纳时不重复请求同一超限上下文。

课堂评价默认采用 `overview`：一段统一总结（最多400字，提示词建议120～220字）与最多3条可执行建议（每条最多240字，建议60～100字）。长课堂分段分析后统一归纳，完整覆盖记录保留，不把未引用分段的原条目追加进报告。

教师展开“按需细分分析”，选择知识点、重点、潜在难点或表达与时间节奏，可输入具体要求。`details` 只生成选中的分类，每类最多5条，不重新生成总结。结果保留既有总结、建议、其它细分内容和教师修订确认。课程、转写或报告在生成期间发生改变时拒绝覆盖；失败保留原报告。旧版六类报告保留在折叠区，可手动生成精简版。

转写与校正、详细分析、结论修订与原文依据默认折叠，减少阅读干扰；播放、修订、确认、删除及 Markdown 导出仍可使用。导出只包含已有内容，不生成空分类。

验证：218项单元/接口测试、42条 Chrome 交互回归通过。新增测试覆盖上述问题、越界操作、历史完整性、报告过期、细分期间人工修订、确认状态与版本、手机布局和导出。

真实模型使用新配置的连接，仅发送构造的资料、历史、课件与课堂文字。7类验证通过：教师修订、指定页关联、多页修改、六页标题直接补丁自动拆批、长历史问候、简短课堂总览、按需细分。标题批量修改用2次模型调用（决定与检查），问候用1次。未发送教师实际资料、转写或自定义提示词。证据：`artifacts/review/live-fixes.json`。测试不替代教学内容或算法正确性审核。

复测：`npm test`、`npm run test:browser`。真实模型隔离验证：`node scripts/verify-edge-fixes-live.mjs`（可用逗号分隔参数只运行指定用例）。密钥仅保存在被忽略的本地环境和后端设置，页面不回显。
