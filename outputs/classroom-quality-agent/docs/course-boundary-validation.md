# 课程边界与交互复测

所有自动化场景使用临时目录或 `artifacts/browser-data`、合成文件和本机模拟服务，不读取教师凭据，不调用真实模型或创建远端问卷。

## 已修复的问题

- **并发上传**：上传槽位在异步空间检查之前登记，六个同时到达的请求只处理三个，其余明确返回稍后重试；完成、失败或取消后释放槽位。
- **失败清理**：创建上传目录失败也释放空间预留。正文提取成功但目录登记失败时，删除本次未录入的正文、恢复副本、原文件及临时文件，不留下孤立资料。
- **满库去重**：每课程200份资料的数量限制在识别资源身份后检查；重传已有文件不新增记录、不增加版本，仍可成功。新文件超过数量限制时拒绝并清理。
- **归档竞态**：保存进入目录写入锁后再次检查课次及所属课程的归档状态，不能通过独立信息版本绕过归档保护。
- **上传反馈**：批量中途失败显示未完成并保留已保存文件。取消期间明确显示正在停止，重新读取完成后再显示已停止，文件选择器随后恢复，避免立即重试被静默忽略。
- **资源入口**：“在备课中查看与编辑”、下载、资源上传、问卷配置及分享入口统一使用操作链接样式。资源入口定位到点击的资源；失效链接明确提示，归档资料可只读定位。
- **窄屏及键盘**：操作链接提供可见焦点，手机使用至少40像素高的点击区域；资源行纵向排列，长名称最多显示三行，完整名称保留在文本和悬停提示中。
