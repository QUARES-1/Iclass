## 尚未关闭的验证

1. **物理麦克风**：在实际设备中录制一段中文，回放并转写；当前 MediaRecorder 回归来自 Chrome 模拟设备。
2. **长课堂人工听校**：按计划人工听取开头、中段、末尾和全部交界，记录遗漏、重复及时间偏差。19 窗口同模型重识别与播放器定位只证明技术行为，不能独立证明识别正确。已有术语误词及最大 0.284 秒的相邻范围重叠保持如实记录。
3. **资源不足与任务时限**：代码有内存不足和超时错误处理；后续上传边界复核已用受控时限终止真实 Python 进程；真实资源压力仍未测，不以一般 503 测试代替。

其他浏览器、GPU、其他演示电脑以及识别准确率量化评测也未验证；需求没有要求预先承诺这些兼容性或准确率指标。教学内容需教师最终确认；演示软件能否直接打开本地 HTML 依其策略，目前配套文件在 Chrome 中独立打开已验证。
