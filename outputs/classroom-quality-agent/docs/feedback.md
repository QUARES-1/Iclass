# 课后反馈操作与数据说明

入口为首页“课后反馈与教学改进”，或 `/public/sprint3.html`。问卷服务、文本模型分别配置；没有金数据凭据时，本地模板、导入、统计和已有成果仍可使用。AI交流和报告生成需要可用文本模型配置。

## 课堂与问卷

每条课堂独立保存日期、目标、模板、反馈、讨论、报告和建议。问卷自动绑定课堂，无需学生选择课程。可按需关联音频页的转写版本、备课页的 PPT 版本；关联读取快照，不修改原资源。

切换或新建课堂时，对话输入按课堂暂存，返回原课堂可继续编辑；尚未发送的输入刷新前仍需处理。切换后清除上一课堂的导入预览、搜索与回听面板。后台旧读取不会覆盖较新的保存结果。

默认模板复用相邻问卷包的原始10字段定义，移除固定八次课选择字段，保留9道业务题。题目和选项标识在重排中保持稳定，新增或复制题目产生新标识。可增删题目、改题型、排序、编辑选项、说明和必填状态；至少保留一道合法题。评分支持1～3、1～5和1～10。

保存模板后，尚未结束且没有反馈的当前课堂选用新版本。已有反馈或已结束的课堂保留原定义，更改供后续课堂使用。“恢复默认草稿”仅载入编辑区，保存后生效，不重写历史问卷。

相同模板、报告和建议再次保存不会追加历史；重复关联同一份来源也不会新建快照。题目和选项编辑器在配置数量上限处停止新增，防止保存前无限堆积。重复操作与内存检查见[测试记录](repetition-validation.md)。

“课程结束”直接启动发布，不等待转写或模型分析。未保存模板编辑保留为草稿，本次使用已保存版本。缺凭据时保留结束和待发布状态，保存凭据后恢复。已过截止时间的待发布问卷须先调整时间。

成功后显示填写链接和在本机生成的二维码。重复结束或重试不重复创建；已创建但字段映射失败时只修复原实例。创建响应丢失或请求后服务重启时进入“待核实”，须核对远端已有表单 Token 后绑定，不能盲目重建。同一表单不能绑定两条课堂；更换凭据后继续操作前核对账户身份。

2026-10-20 已使用专用测试问卷验证真实创建、手机与桌面匿名填写、反馈更新回流及到期关闭。真实模型使用合成问卷、转写和课件进行联调，结果与限制见[真实联调记录](sprint3-live-validation.md)。未刻意耗尽服务商额度，限流异常仍主要由夹具验证。

## 同步、截止与排除

同步从首页读取全部分页，核对结构后整体提交。部分页失败、游标异常、远端改题或同步期间本地反馈变化时保留原统计。再次同步会更新旧回答的修改，无变化不增加份数、不使报告过期。问卷开放且页面可见时每60秒尝试同步，后台标签页不自动同步。

所有课堂共用问卷请求队列，创建优先。`FEEDBACK_API_INTERVAL_MS` 控制请求起始间隔，默认1000毫秒；实际仍受服务商权限和额度约束。

取消或删除课堂时，尚未执行的问卷请求立即移出队列。手工绑定遇到课堂并发修改时拒绝本次绑定，不占用表单归属；发布仍在处理时应等待其结果再核实绑定。

截止输入按浏览器本地时区转换成绝对时刻，发布请求携带截止设置。远端是否停止填写须在金数据核对；本地将达到截止时刻及之后的反馈单列为晚到，不计入本轮有效统计。截止后仍可手动补同步截止前反馈。提交时间须包含秒和时区，缺失或精度不足的单列“时间待核对”。

逐题以有效回答为分母，多选同一选项只计一次，百分比之和可能超过100%；非法评分不记为零分。教师排除状态及原因不会被同步覆盖。样例按原课程拆成独立课堂，重复载入或重命名后再载入不重复；样例课堂不发布到金数据，样例与正式反馈不能混合导入。

## JSON 导入

先下载当前课堂的格式说明，按模板中的题目与选项标识填写。外层为对象加 `records`，也支持直接导入数组。以下仅适用于未修改的默认模板：

```json
{
  "records": [{
    "id": "local-001",
    "source": "local",
    "submittedAt": "2026-10-20T12:30:00+08:00",
    "answers": {
      "q-difficulty": "hard",
      "q-pace": "pace_fast",
      "q-understanding": "understood_some",
      "q-clarity": 4,
      "q-interaction": "interaction_ok",
      "q-rating": 4,
      "q-comments": "希望展示完整函数及调用。"
    }
  }]
}
```

单选及下拉使用选项标识，多选使用标识数组，评分为整数，开放题为文本。稳定 `id` 用于去重更新；未提供时按回答内容生成标识，完全相同的回答会视为重复，正式汇总应提供独立记录标识。在线记录沿用 `online-序号` 和 `instanceToken`，再导入时保留身份字段。

导入以 `answers` 为准；文件中残留的旧 `rawAnswers` 不会覆盖教师的答案修正。提交时间须为实际存在的日期，不能使用会被自动换算的“2月30日”或24点写法。

可提供外层 `classId`、`template` 和逐条 `instanceToken`，系统核对归属及定义。预览显示新增、更新、重复与逐条错误，确认后才提交；部分错误须明确选择“仅导入有效记录”。预览后模板、反馈或截止时间变化则重新预览，一小时未确认的预览失效。相同输入在同一课堂状态及小时内复用预览，后续预览会触发过期文件回收。选择坏文件后旧预览失效。

默认限制为 UTF-8 `.json`、4 MiB、每课堂及单次处理10000条反馈、单题文本4000字符、80题和每题80个选项。`.env` 可调整 `FEEDBACK_MAX_*`，上限见[部署说明](setup.md)，重启后页面显示实际值。外层 HTTP JSON 请求仍限6 MiB；单个存储文档限100 MiB，超限保留原数据。

## 整体复盘与建议

智能体根据要求直接回答、读取资料或自行规划，默认形成整体总结和具体建议；只有问卷、只有音频或组合资料均可分析，缺少来源应如实说明。无有效资料时提示补充。事实观察须引用存在的证据，可能原因标为推测；证据存在不代表模型判断必然准确，仍需教师复核。

长输入分批分析并保存已完成部分，再汇总成整体报告。输出达到额度时尝试缩小批次；单条内容或最终汇总无法容纳、预算耗尽时明确失败并保留检查点，不提交半份报告。暂停后可继续，重启后未完成任务转为暂停，不自动恢复在线调用。恢复沿用原输入、提示词和非密钥设置，重新取得当前密钥；采用新模型或提示词需重新发起。

同一课堂同时只允许一个报告写任务，普通问答和教师编辑仍可继续。后台候选不覆盖期间保存的教师修订；建议发生并发修改时提示冲突。新反馈、重新关联、转写派生校正版或目标课件版本变化使旧报告待更新。历史依据保持当时内容；原音频删除后无法回听，转写依据仍保留。

报告可修订、确认、恢复历史和导出 Markdown；过期稿不能确认为最新。导出先保存当前编辑，等待期间的新编辑会阻止旧稿下载。清空讨论保留成果，迟到回复不恢复旧对话。

确认报告、携带建议前会保存相应草稿；等待期间继续编辑时保留新输入，并提示保存后重新操作。后台产生新报告时，正在编辑的旧稿仍保留，“查看依据”对应正在编辑的报告。同一智能体任务可读取并继续完善自己刚保存的版本；教师并发修订仍受保护。写入候选先检查完整结构与引用，缺少建议数组不会被当作清空建议。

PPT 建议可独立生成、编辑、恢复历史和交接，不要求先有完整报告或目标 PPT。“按建议修改 → Sprint 1”固定所选建议版本，URL只携带交接标识。接收页保留已有草稿和异步载入期间的新输入，不自动选择资源或发送任务；教师确认目标并发送后进入既有备课修改流程。

建议载入临时失败时可原地重试，保留已输入内容。成功发送后会清空对应草稿缓存，刷新不再恢复已经发送的要求。

## 数据与删除

数据在 `data/feedback-*.json`，不公开服务、不加入 Git。资料内容按哈希存于 `feedback-material-*`，重复问答复用相同资料；每任务的 `feedback-input-*` 保存当时上下文与资料引用。任务检查点不存密钥。

删除课堂使本地任务失效，不删除远端表单、原录音或原课件。请求发出后删除课堂仍可能在远端留下实例，需人工核实。删除标记、不可变资料及检查点文件不立即物理回收；迁移或清理前停止服务并备份整个 `data/`。
