# 本地示例重复载入修复

日期：2026-10-11。问题：旧“载入本地示例”每次追加四份资料和五份资源；上一轮只增加了上限检查，没有使该操作幂等。用户多次点击后，18 条资料 / 25 份资源中的示例达到四套，触发资料数量限制。

## 修复行为

- 各类示例保存稳定 `sampleKey`，只补充缺少的资料或资源。教师资料和 AI 生成资源不参与示例去重，不能仅凭相同名称删掉用户内容。
- 已改名、编辑、恢复或确认的示例仍算已载入，不再重新追加原始样例；已有内容、历史、确认、当前选择及试玩状态保留。
- 识别旧数据中的示例原始版本。仅合并相同的示例资料，以及未修改、未确认、未被引用、未选中的重复资源。所有版本中的 PPT 关联和对话引用均保护相应资源。
- 删除旧重复数据前，把完整工作空间写入 `data/backups/workspace-before-sample-dedup-*.json`，文件权限为 0600。该目录不通过静态服务公开。
- 完整示例再次载入不写文件、不增加 revision/消息、不清空知识点，也不重置当前 iframe。达到数量上限时，只对实际缺少的示例计算新增量；已有完整示例仍能再次点击。
- 同版本并发重复请求可返回已载入结果。过期请求若会改变数据则拒绝，避免用户清空后被旧请求重新加入样例。
- 按钮等待时禁用并显示“正在载入…”，前端串行处理；成功后说明是补充、整理还是没有重复添加。
