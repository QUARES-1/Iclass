# 实现说明

实现保持原生 HTML/CSS/JavaScript 与 Node.js。新增模块与边界如下：

| 模块 | 职责 |
| --- | --- |
| `src/store.js` | 单文档提交串行化、revision 检查、临时文件原子替换；100 MiB 元数据上限 |
| `src/workspace.js` | 资料上下文、稳定资源/页面 ID、版本分支、字段补丁、确认规则、固定版本互动引用 |
| `src/model.js` | 后端 JSON 模型调用、超时和输出结构；对话新建/修改/澄清/建议/关联协议，无修改失败模板回退 |
| `src/interactive.js` | 声明式四种互动的数据检查与单一 HTML 运行器；预览和导出复用同版本 |
| `src/runtimeCheck.js` | Chrome 离线环境校验 AI 候选主要操作、判定、提示和重置，失败不提交 |
| `src/classroom.js` | 独立课堂数据、识别原稿/校正版、过期报告、证据与确认、旧数据清理 |
| `src/analysis.js` | 按真实片段逐段覆盖、分段失败反馈、汇总与原始证据检查 |
| `src/api.js` | 持久化业务接口、流式音频文件、异步任务、版本提交与音频范围播放 |
| `src/speech.js` / `speech/worker.py` | 独立 Python 进程协议、单推理队列、探测/转换/VAD/识别、模型时间与块偏移 |
| `public/main.js` / `public/sprint2.js` | 教师编辑、未提交草稿保护、串行保存、工作台与音频证据回放 |

PPT 在创建时完成可见页面的分页与稳定 ID 分配，导出使用 canonical 模型，不能导出时重新改变页码。过长页面修改要求拆分，不会悄悄影响其他页。正式导出的全部有效页门槛同时在共享导出模块与页面控制中检查。

AI 对现有 PPT 只能提交字段补丁或明确增删操作，不返回整份旧内容覆盖。后端固定当前版本，检查修改范围，再原子保存新版本；期间发生其他保存会拒绝候选覆盖。前端显示的修改摘要绑定真实提交版本。

互动脚本由应用提供，模型只提交可验证的数据。预览使用 `sandbox=allow-scripts` 的不透明来源 iframe；页面 CSP 禁止外部连接、表单和资源请求，消息检查窗口来源与版本 token。全屏由工作台容器提供。静态服务只允许公开页面与明确的共享纯模块，不公开后端代码、配置、测试、模型、资料或录音目录。

语音没有后台自动下载或示例回退。上传先流式保存临时文件、真实探测成功后原子提交录音记录；失败保留原录音。每次推理只解码一块，块内 VAD 区间独立识别，避免移除静音后产生错误的大跨度对齐。转写原稿保存处理时间、模型、设备、峰值内存及每块覆盖。校正版建立带父版本 ID 的独立记录，标记 `original: false`，原识别记录不变。单独删除原音频保留文字和报告，明确影响回放；排队、处理、模型加载和识别期间均禁止删除输入或清空课堂。服务重启会把未完成任务标为失败并允许重试；仅构造服务实例或读取静态页面不会触发数据恢复，自动测试使用隔离存储目录。

课堂分析仅接收 Sprint 2 内当前课程说明、校正版、识别时间与文本统计。没有自动读取 Sprint 1 内容，也没有用教师音频推断学生表现。结论存在性检查不能证明模型内容正确，教师仍需复核证据与确认。真实备课流程已通过本轮排序课程样例验收，完整课堂报告结果见 [真实验证记录](live-validation.md)。
