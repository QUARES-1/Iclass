# 实现说明

应用由原生HTML/CSS/JavaScript前端、Node.js服务与独立Python语音进程组成。默认使用本地文件存储，没有数据库或额外常驻语音服务。

## 数据与任务

备课工作区和课堂记录独立保存。修改使用稳定ID、父版本、revision及临时文件替换；输入或目标版本在任务期间改变时，拒绝覆盖教师成果。

模型决定回答、读取资料、直接操作或制定计划；后端检查范围、结构、运行结果和预算。备课任务记录规划、调用、草稿和检查结果，分批保存检查点，通过检查后提交新版本。任务可暂停和继续，清空上下文后原暂停任务不再继续。

转写逐块解码，在VAD区间内识别并叠加实际时间偏移。每块完成后保存识别进度，继续时跳过完成部分，最终提交完整转写。简体转写作为独立版本，不覆盖原稿。

长课堂分析全部有效片段后生成整课报告。分段结果保存于检查点，最终完成后提交报告。总结篇幅用于引导精简，建议不按固定数量裁剪；有效证据、完整JSON和存储安全上限仍受校验。

## 预览与导出

PPT实际分页在保存前完成，预览与导出使用同一模型，正式导出要求全部有效页面确认。示例代码优先保留完整函数或代码部分，超长函数仍按完整行分段。

模型提交声明式互动数据，应用提供执行脚本。预览使用隔离iframe，后端在Chrome离线环境中检查操作、判断、提示和重置。PPT关联互动使用固定版本，配套HTML与引用快照一致。

全文转写不受分页和搜索过滤影响，导出前保存当前校正。报告导出绑定存储版本，等待期间新增修改会阻止下载旧稿。

## 配置与访问

Sprint 3 使用独立 `feedback-*` 命名空间，关联转写和课件时保留不可变版本。资料按内容哈希复用，任务输入保存引用；历史报告的依据不随最新资料改变。任务记录不包含模型密钥，恢复保留原非密钥设置，凭据在运行时取得。发布请求是否已发送先持久化，响应不确定时不得自动重建；同步全分页校验完成后整体合并。

课后反馈智能体只允许读取、分析、写报告和写建议，没有 PPT 写工具。交接固定已保存建议，由 Sprint 1 接收展示并保留教师草稿，实际修改仍需教师发送。详细数据与操作约定见[反馈说明](feedback.md)。

密钥保存在后端配置中，前端仅得到已配置状态。界面保存的模型配置优先于`.env`，任务启动时读取配置快照。

默认仅监听本机。静态服务公开界面和允许的共享模块，配置、录音、模型、数据与后端源码不作为静态文件提供。模型生成及分析访问所配置API，语音识别使用本地权重。

## 课程结构

`src/courses.js`管理课程目录、课次、教师原文件、资源选择与跨课次建议读取。`src/api.js`按URL中的课次ID复用原有三部分API，课次保存在独立目录，设置与模板共用；空课次不会回退到全局旧数据。`public/course.html`、`lesson.html`及`course-context.js`提供课程入口与统一课次导航，`lesson-scope.js`统一处理API、媒体、页面链接和浏览器草稿的归属。详细边界见[课程与课次](course-structure.md)。
