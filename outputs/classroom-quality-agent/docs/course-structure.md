# 课程与课次

课程是应用的顶层入口。每门课程包含若干课次，以及可由多个课次选用的课程资料库。

## 教师怎么使用

1. 在首页创建或进入课程，例如“数据结构”。
2. 添加课次，例如“第3讲 · 平衡树”，填写日期和教学目标。
3. 向课程资料库上传教师已有课件、讲义、图片、音视频或添加网页链接。
4. 在课次概览选择本节课实际使用的资源，也可以选择本课次备课生成的多个课件或互动。
5. 按需进入备课、课堂录音或课后反馈，各页面始终显示所属课程和课次。使用反馈和录音不要求先生成课件。
6. 下课时在该课次的反馈页结束课堂并发布问卷。反馈记录已经属于该课次，无需另建一组课堂再手动归类。已有本课次转写时会默认关联，教师可以解除或更换。
7. 教师选择将改进建议带入哪一个课次的备课页。跨课次交接只载入建议，目标课次的课件由教师选择，不自动带走或改写原课件。

## 资料来源与使用范围

- **教师自带文件**：完整保留原文件，可下载；与 AI 生成内容并列选用。
- **网页链接**：保存链接和教师的教学说明，不自动抓取网页。
- **备课生成内容**：按本课次保存，可选择多个资源作为实际教学背景。

选中的资源进入本课次的课后复盘，正文和说明有独立引用标识及历史快照。“加入备课资料”将选定资料的正文或教学说明加入该课次备课上下文；重复加入相同内容不会复制，其他课次的备课资料不受影响。生成的课件和互动不会未经选择就被视为课堂实际使用的内容。

文件单份最多50 MiB；课程最多200份资料，每个课次最多选择40份资源、正文合计50万字符。TXT、MD、DOCX、PPTX在15 MiB以内可提取文字。PDF、旧版Office、图片、音视频、HTML和ZIP保存原文件，可补充教学说明供AI参考；未提取的正文不会被声称已经分析。识别音频请进入本课次的“课堂录音”。

课程列表最多100门、课次总计1000节、资料总计2000份。列表分页展示。课程和课次可归档及恢复；归档保留历史，进行中的任务须先暂停或完成。删除资料前必须解除所有课次引用，并由教师确认；已加入备课的文本与已有复盘快照继续保留。

## 保存和隔离

- `data/course-catalog.json` 保存课程、课次、资源元信息和选择关系。
- `data/course-files/` 保存去重后的教师原文件；`course-content-*.json` 保存提取文字。
- `data/lessons/<课次ID>/` 分别保存备课资源、对话、音频、转写、问卷、报告、任务和恢复副本。
- 模型配置、金数据连接与预设问卷模板在项目中共用；每次发布仍固定当时的模板版本。
- 请求与页面通过 `lesson` 参数明确归属，服务端不保存一个会影响所有标签页的“当前课堂”。错误或不存在的课次不会回退到其他工作区。
- 浏览器备课和音频草稿按课次及标签页隔离，反馈当前记录和建议交接草稿也按课次区分。
- 课程信息、课次信息、资源说明和资源选择分别检查自身版本。刷新列表不会绕过原有并发保护；保存冲突保留输入，主动重新载入时须确认是否放弃本页修改。
- 所有课次与资料共用项目的数据空间额度，默认5 GiB，不会每建一个课次就增加一份额度。转写共用执行队列，避免同时加载多份语音模型。

在课次内打开设置，“数据与恢复”的归档与清理作用于该课次；空间同时显示课次占用及项目总占用。直接打开全局设置时，历史归档处理原有工作区；课程目录、教师资料库和其他课次不会被一并清理。备份和迁移应复制整个 `data/`。

## 旧数据

升级前的全局工作区无法可靠推断它属于哪门课程或哪一课次。系统将其登记为“历史教学资料 → 原有工作区”，保留原文件、历史反馈分组及已有关联，不移动、复制或覆盖原记录。反复启动不会重复登记。新教学从课程中创建课次，按新结构保存；旧页面地址仍可读取原工作区。


接口测试覆盖课程与课次重试去重、历史数据保护、跨课次和跨课程隔离、共享设置、原文件下载、并发上传去重、格式和大小边界、重复加入备课、资料引用与报告过期、自动关联转写、归档恢复、共享空间额度、解除引用后删除及跨课次建议交接。浏览器覆盖课程起步、教师资料、多个标签页、等待中编辑、导航归属、重复上传、下载、手机布局、归档与跨课次建议刷新。

最新复测包含上传并发、失败清理、满库去重、归档竞态、资源定位和窄屏操作样式。逐项结果、重复操作数据及日志见[课程边界与交互复测](course-boundary-validation.md)，整体测试结果见[测试说明](testing.md)。真实工作目录的27份原记录和API配置校验值保持不变；本轮使用本机模拟服务，未调用真实模型或创建远端问卷。
