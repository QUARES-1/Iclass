# 课后学生反馈问卷设计

本问卷是「课堂质量改进智能体」课后反馈（Sprint 3）的数据采集入口，用于收集学生对单次课堂在知识难度、课堂节奏、互动体验与理解程度四个维度的反馈，为后续课堂诊断与下一节课优化提供依据。

## 1. 设计目标

- 对标项目「课下反馈」环节：汇总知识难度、节奏、互动和理解程度。
- 保持匿名、最小化采集：不收集姓名、学号、手机号等身份信息。
- 填写成本低：约 1 分钟可完成，除一条开放建议外均为选择题或评分题。
- 数据可统计：所有选择题选项都显式定义 `api_code`，便于接口拉取后聚合统计。

## 2. 题目与字段对照

表单共 10 个字段，字段 `api_code` 按顺序固定为 `field_1`～`field_10`。

| 字段 | 题型 | 题目 | 选项 / 取值范围 | 必填 |
| --- | --- | --- | --- | --- |
| `field_1` | 下拉框 | 本节课对应的课堂 | 第1次课～第8次课（session_01～session_08） | 是 |
| `field_2` | 单选 | 本节课内容难度 | 太简单 / 比较适中 / 偏难 / 太难 | 是 |
| `field_3` | 单选 | 课堂节奏 | 偏慢 / 适中 / 偏快 | 是 |
| `field_4` | 单选 | 核心知识点的理解程度 | 完全掌握 / 大部分掌握 / 基本掌握 / 不太理解 | 是 |
| `field_5` | 评分 | 讲解清晰度 | 1～5 分 | 是 |
| `field_6` | 单选 | 课堂互动是否充分 | 很充分 / 一般 / 不够充分 | 是 |
| `field_7` | 多选 | 你感到最难的部分（可多选） | 基本概念 / 算法思想 / 代码实现 / 复杂度分析 / 例题应用 | 否 |
| `field_8` | 多选 | 希望下节课加强（可多选） | 原理讲解 / 示例代码演示 / 课堂练习 / 答疑与讨论 / 复习与总结 | 否 |
| `field_9` | 评分 | 对本节课的整体评价 | 1～5 分 | 是 |
| `field_10` | 多行文本 | 其他建议（可选） | 自由文本 | 否 |

## 4. 数据取值约定

- 单选 / 下拉框：提交选项的 `api_code`（字符串）。
- 多选：提交 `api_code` 数组；未选择时提交空数组 `[]`。
- 评分：提交 1～5 的整数。
- 多行文本：提交字符串；未填写时提交空字符串 `""`。

## 5. 样例数据

`data/sample-entries.json` 提供 8 份样例填写数据，覆盖第 1、2、3、5 次课，包含“偏难 / 节奏快 / 理解不足”“适中 / 掌握良好”等不同情况，以及 3 条开放建议，便于下一轮同学验证问卷统计模块。
